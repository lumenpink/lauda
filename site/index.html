DIOXUS // SMOLCLIENT

LAUDA

O Smolclient de Correio Minimalista
Interface ultraleve para leitura em texto puro e redação rápida sem a sobrecarga de clientes IMAP/SMTP tradicionais. Compilação nativa Android NDK e Linux desktop via Dioxus, consumindo micro-API segura sobre rede fechada.

01. VISÕES TRIFÁSICAS

Alternador nativo entre txt auto (Markdown processado), txt original (texto cru com espaçamento fixo) e html (container sandboxed).

02. REDAÇÃO SEM TRAVAS

Campo From livre com autocompletar de aliases favoritos e composição ágil em fonte monoespaçada.

03. NDK DESDE O DIA ZERO

Arquitetura compilada para Android NDK e desktop Linux com a mesma árvore declarativa Dioxus.

ARQUITETURA DO WORKSPACE

lauda/
├── lauda-types/    # Contratos serde de dados compartilhados
├── lauda-server/   # Micro-daemon HTTP axum + ponte Dovecot
└── lauda-client/   # App Dioxus Mobile (Android NDK) + Desktop
